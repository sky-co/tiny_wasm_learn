WebAssembly / AArch64 Toolbox

WAST conversion, Wasm disassembly, and AArch64 assembly/disassembly. Connects only to the local service.

1. wast2json

Paths are relative to the project root. Supports .wast / .wat / .wasm files and HTTP(S) URLs.

Local conversion creates or overwrites the matching JSON and numbered Wasm files next to the source. Remote files are saved in the service's temporary directory.

Ready to convert.

2. wasm-objdump

Output from wasm-objdump -d -x will appear here.

3. AArch64 Disassembler

Enter 8 hexadecimal digits, optionally prefixed with 0x and suffixed with U. Automatically converts to little-endian bytes.

Ready to disassemble.

4. AArch64 Assembler

Uses llvm-mc to display little-endian bytes and the 32-bit instruction word with a U suffix.

Ready to assemble.

5. AArch64 Binary to Hex

Enter one 0 or 1 in every box, then click translate. Bits run from 31 (most significant) to 0 (least significant), matching the ARM encoding diagrams. Each group of four bits produces one hexadecimal digit.

Fill all 32 bits and click translate.
